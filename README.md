# VCStockRank

面向 A 股横截面排序研究的可复现原型：用变量维度注意力（VCFormer）和时序模式注意力（TPA）融合量价因子，同时预测未来 5 日超额收益排序与波动率。

> 本项目用于统计建模与工程实践，不构成投资建议。仓库不提供可直接用于实盘的收益承诺。

## 解决的问题

传统收益回归容易被噪声和极端值主导。本项目把目标改写为“同一交易日哪些股票的未来相对表现更好”，并把数据下载、因子计算、训练、组合构建和评估拆成独立模块，便于检查每一步的口径。

核心能力：

- 50+ 个量价与时序特征，包括动量、流动性、波动率期限结构和滚动统计量；
- VCFormer 建模变量间交互，TPA 提取多尺度时序模式；
- 排序、未来波动率与分解约束的多任务训练；
- 风险平价权重、交易成本和滑点模拟；
- IC、ICIR、分层收益、回撤与风险收益指标。

## 评估协议 v2

旧版本曾在全样本上拟合并回测，且包含双向填充、双边 STL 和全样本统计量。这会把未来信息带入历史特征，因此旧 README 中的高收益数字已撤回，不能视为样本外结果。

当前代码执行以下约束：

1. 按交易日期切分 70% 训练、15% 验证、15% 测试；
2. 在训练/验证边界保留 5 个交易日禁入期，避免未来 5 日标签跨越边界；
3. 缺失值只向前填充，初始未知值不从未来回填；
4. 时序分解、Hurst 和去极值只使用当日及历史信息；
5. 模型只在验证集上早停，只在测试区间生成回测信号；
6. 信号在当日收盘后生效，按 5 个交易日调仓，并计入交易成本和滑点；
7. 未来 5 日分层收益按非重叠窗口统计。

旧 checkpoint 缺少 `protocol_version=2` 时会被拒绝，防止误用历史结果。

## 快速开始

### 中文可视化工作台

无需先安装深度学习依赖，即可体验界面和查看已有回测结果：

```bash
pip install -r requirements-ui.txt
streamlit run app.py
```

浏览器打开 `http://127.0.0.1:8501`，提供三个页面：

- **研究概览**：明确标注的演示数据、CSV 导入、本地实验选择、日期筛选、净值与回撤图、每日明细和 CSV 导出；
- **开始研究**：设置日期、股票数量与训练轮数，启动独立任务，查看实时日志，或停止当前会话中的任务；
- **股票池**：按名称和代码搜索，保留股票代码前导零，下载完整股票池。

导入 CSV 需包含 `date,return` 两列，每个交易日一条记录。收益用小数（`0.01` 表示 1%），应已包含交易成本。空数据、无效日期、重复日期和非有限收益会显示具体错误。图表与指标按所选区间重新计算，夏普采用 2% 年化无风险利率、252 个交易日；界面将初始本金计入回撤，首日亏损也会显示。

启动真实训练前，请再安装 `requirements.txt`。工作台调用现有训练与评估流程，每次从头训练，将股票池快照、参数、日志、模型及结果单独保存到 `runs/<实验编号>/`，不会覆盖原命令行产物。只有成功完成的工作台实验会出现在结果选择器中。原命令行生成的根目录 `backtest_returns.csv` 也可直接查看。

关闭页面不会停止任务；停止按钮只管理当前浏览器会话启动的进程。重新打开后，已完成结果仍可查看。工作台面向本机单用户运行，默认仅监听本机地址。

界面测试（无需下载行情或安装 PyTorch）：

```bash
pip install -r requirements-ui.txt pytest
python -m pytest tests/test_dashboard.py -q
```

### 命令行完整流程

要求 Python 3.10+。数据来自公开行情接口，首次运行需要网络。

```bash
git clone https://github.com/ilovemiku520/VCStockRank.git
cd VCStockRank
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

已有 v2 checkpoint 和因子文件时，可单独执行：

```bash
python backtest_main.py
```

运行自动检查：

```bash
pip install -r requirements-dev.txt
pytest -q
```

## 项目结构

```text
data/              数据下载、因果清洗与因子构建
model/             VCFormer、TPA、分解与多任务模型
training/          时间序列数据集、损失函数与训练器
portfolio/         组合优化与信号滞后回测
evaluation/        IC、分层收益与解释分析
tests/             时间完整性回归测试
config.py          数据、模型和组合参数
main.py            端到端训练与样本外评估入口
backtest_main.py   v2 checkpoint 独立回测入口
```

## 复现结果的最低要求

任何对外展示的实验结果应同时提交：

- 固定股票池、数据起止日期与数据源版本；
- 训练/验证/测试日期及禁入期；
- 随机种子、完整配置和 checkpoint 哈希；
- 测试区间逐日收益、交易成本、基准和指标计算脚本；
- 对停牌、退市、复权和幸存者偏差的说明。

在这些材料齐全前，本仓库只展示方法和工程实现，不展示不可核验的收益率。

## 已知限制

- 默认股票池只有 25 只，不能代表全市场，仍可能存在幸存者偏差；
- 当前使用单次时间切分，尚未实现完整 walk-forward 和多市场阶段稳健性检验；
- 行情质量、复权口径和交易可行性仍需独立核验；
- 深度模型结果对随机种子和样本规模敏感。
